# Languages (i18n)

The UI speaks German and English. German is the reference language, because
the app trains for the German AP2 exam. The choice is stored in the browser
(`netzplan-zeichner-v1-lang`) and set with the `DE`/`EN` button in the toolbar.

## How texts are defined

All user visible texts live in `src/i18n/`. One file per area, for example
`toolbar.ts`, `achievements.ts`, `check.ts`. Each file exports dictionaries
made with `defineText(de, en)`:

```ts
export const toolbarText = defineText({
    check: "Prüfen",
    savedAt: (when: string) => `Gespeichert ${when}`,
}, {
    check: "Check",
    savedAt: (when: string) => `Saved ${when}`,
});
```

- `en` must have exactly the shape of `de` (`NoInfer`), so a missing or extra
  key is a type error.
- Texts with values are functions with typed parameters, never string
  templates with placeholders.
- Data that contains text (palette items with presets, examples, guide
  chapters) is a dictionary of the whole structure, or is built by a function
  from a text table.

## How texts are used

| Where | How | Re-renders on switch |
| --- | --- | --- |
| React component | `const t = useText(toolbarText)` | yes |
| Everything else (lib, actions) | `text(toolbarText).check` | no, read on call |

Code in `src/lib` that produces texts (check messages, exercise names) calls
`text()` when it runs. Components that show such results subscribe to the
language (`useLocale(s => s.locale)`) and recompute, so a switch updates the
check panel at once.

## Adding or changing a text

1. Add the key to the German dictionary of the matching file in `src/i18n/`,
   then the English one. `npm run typecheck` reports a missing side.
2. Use it with `useText` in components or `text()` elsewhere. No literal
   UI strings in components or `src/lib`.
3. The e2e suites assert German texts. After changing a German text, search
   `tests/e2e/` for the old wording.
4. Switch the language in the running app (`DE`/`EN`) and check that long
   English texts still fit (buttons, sidebar tiles, phone width).

## What is not translated

- Persisted ids and keys: node types, mode keys (`netz`, `akt` …), achievement
  ids, field keys (`faz`, `fez` …), storage keys.
- The content of a user's diagram. Switching the language does not rewrite
  what someone drew. New elements get default texts in the current language.
- The achievement name „Ihr werdet mich niemals besiegen“ and Rainer.
